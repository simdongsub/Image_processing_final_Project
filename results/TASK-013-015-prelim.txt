[수식·코드 대조 (model.py)]
- luminance(x) -> gaussian(y, brightness_sigma=3.0) -> strength = g_min + (1-g_min)*(1-B).clamp(0,1)^kappa -> enhanced = x + strength*(E - x)
- 결합 시 밝기 혼합이 노이즈 평활화보다 먼저 적용됨, none 베이스라인 경로 미변경
- EnhancementConfig 제약 확인: 0 <= g_min <= 1, kappa > 0, brightness_sigma > 0

[Colab Tesla T4 실측 출력]
- 상수 입력(0.0, 0.2, 0.5, 1.0): brightness 맵 값 일치(atol=1e-5), 출력 [0,1] 유한, 모든 파라미터 gradient 유한 통과
- 좌(암부 0.05) / 우(명부 0.90) 합성 입력 (강한 밝기 증가 bias=-2.0):
  * none   dark/bright mean: 0.9998 / 1.0
  * bright dark/bright mean: 0.9142 / 0.933
  * brightness map dark/bright: 0.1127 / 0.8373
- g_min 단조성 (bright half mean):
  * g_min=0.0 -> 0.9163
  * g_min=0.2 -> 0.933
  * g_min=0.8 -> 0.9833
  * g_min=1.0 -> 1.0
- kappa 단조성 (mid=0.5 mean):
  * kappa=0.5 -> 0.8828
  * kappa=1.0 -> 0.8
  * kappa=3.0 -> 0.65
- 실제 LOL 이미지 (our485/low/10.png):
  * out shape=(1, 3, 400, 600), map shape=(1, 1, 400, 600)
  * range=(0.0, 0.2003), all_grads_finite=True
