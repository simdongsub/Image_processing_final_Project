## 수행 순서

1. LOL 출처·버전과 공식 분할을 확정하고 실제 이미지 배치/크기를 확인한다.
2. Colab에서 기본 모델과 개선 모델의 짧은 예비 학습을 하고 소요 시간을 측정한다.
3. 가장 느린 구성도 3시간 이내인 공통 에폭·입력 크기·배치를 확정한다.
4. 검증 세트에서 작은 후보군으로 모듈 값을 정하고 JSON으로 기록한다.
5. 같은 모듈 설정 파일과 고정 분할로 A~D 본 실험을 한다.
6. 동일 테스트 세트에서 평가하고 이미지별 수치와 성공/실패 사례를 분석한다.
7. 시간이 허용되면 시드 3회 실험을 추가한다. 초기화 시드만 바꾸고 split-seed는 유지한다.
8. 실제 측정한 시간·장비·조건·수치, 참고 출처와 한계를 보고서에 기록한다.

## 아직 검증하지 않은 사항

실제 LOL 데이터 호환성, 성능 개선 여부, T4 시간 한도, Drive 세션 종료 후 재개. 모듈 기본값과 예시 에폭은 최적값이 아니다. 개선이 실패하면 밝기 저하, 에지 오인, 평활화에 따른 디테일 손실 등을 저장된 맵·확대 그림으로 분석한다.
